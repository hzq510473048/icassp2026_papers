# ICASSP 2026 papers

Downloaded collection of **4,436 PDFs** from the 4,589 entries in the ICASSP 2026 proceedings. The remaining **153 entries** were not collected. Downloading has ended at the owner's request.

## Download

The PDFs are stored as seven independent ZIP bundles in the [Release](https://github.com/hzq510473048/icassp2026_papers/releases/tag/papers-2026-10-13), totaling approximately 11.7 GB. Each bundle is under 2 GB. Download only the bundles you need, or download all seven for the complete saved collection.

Each bundle contains original batch ZIP files under `zips/` and/or individual PDFs under `supplemental/`. Extract the bundle, then extract its batch ZIPs to access those PDFs. The seven bundles are independent archives, not split volumes.

## Index and verification

- [`papers.tsv`](papers.tsv): all 4,589 entries, titles, saved/missing status, bundle names, archive paths, and PDF filenames.
- [`missing.json`](missing.json): the 153 uncollected entries.
- [`SHA256SUMS`](SHA256SUMS): SHA-256 checksums of the seven release bundles.

All saved batch archives passed CRC validation, PDF-header checks, expected-title matching, and SHA-256 verification. Supplemental PDFs were checked for PDF headers, EOF markers, and hashes. Late batch archives recovered 27 additional PDFs during the final audit.
